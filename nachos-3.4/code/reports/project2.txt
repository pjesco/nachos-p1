For this project, we implemented the system calls as functions in the exceptions.cc file.
Using the professor's videos as guides, we also have helper classes such as AddressSpace, PCB, and PCBManager.
To run tests, simply add a test program to the nachos tests directory, make, then from userprog run ./nachos -x ../tests/[program name].
We tested our program using the various provided tests and our output ended up matching the provided output.
Our main issues when dveloping were in the Join and xit calls, as we were initially not dallocating memory properly but also
needed to save the pcb of an exiting process in case the parent was performing a Join.
We also needed to act more checks in Join to make sure a valid pid was being passed through, which caused a segfault before we fixed it.
